Security boundary

What this console will not do

It never reads t9k-test/t9k-config.yaml or the SSH private key through broad Workspace grants. A kubeconfig file is readable only when explicitly supplied as an instance input. Tokens are held in memory, never persisted, logged, or added to conversation.

Background bridge startup is delegated to the Agent so job IDs, lifecycle and cancellation remain visible in the conversation.
